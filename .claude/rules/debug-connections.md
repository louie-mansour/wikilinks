# Debug node connections

Useful article pairs for testing rendering and graph behavior.

## Lots of nodes

**Carex curaica → List of mayors of Elgin, Illinois**

Two obscure articles with no obvious link — exercises long paths, many intermediate nodes, and large graphs.

## One node (same article)

**Albert Einstein → Albert Einstein**

Start and end are the same article. Tests the zero-hop / single-node edge case.

> Note: "ALbert Einstein" (capital L) is a common typo for this pair — treat as the same node.
